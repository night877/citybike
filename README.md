# CITY BIKE: новая версия сайта (черновик)

Предварительная версия citybikensk.ru для согласования. Текущий сайт на Тильде не менялся.
Страницы закрыты от поисковиков (`noindex`, `robots.txt`), чтобы не дублировать настоящий сайт.

- `docs/` — готовый сайт, его отдаёт GitHub Pages.
- `data/` — прайсы, товары, разделы витрины, диагност.
- `tools/build.py` — сборка страниц: `python tools/build.py`. Для настоящего домена: `--prod`.

Товары добавляются в `data/products.json`, разделы описаны в `data/catalog.json`. Если в подразделе нет товаров, показывается карточка-пример.
